# tracker

Память агентов между сессиями и проектами (Claude Code, Codex, OpenCode): задачи - md-файлы в `~/tasks` под git, каждая правка ведёт к сессии агента, которая её сделала. Агенты работают через CLI `tk`, человек - через TUI.

## Стадия

MVP. Работают ядро записи, семь базовых команд `tk` (`new`, `show`, `edit`, `comment`, `note`, `rm`, `list`) и цикл агента (`ctx`, `take`, `move`, `set`, `check`, `done`, `backup`), идёт приёмка З2. TUI и коннекторы агентов - в З3-З4.

## Быстрый старт

Требования: Go 1.27.2, `golangci-lint` 2.x, git.

1. Собрать: `make build` (бинарь `bin/tk`).
2. Задать базу: `export TRACKER_HOME=$HOME/tasks` (без переменной берётся `~/tasks`).
3. Создать задачу: `bin/tk new "первая задача"`.
4. Проверить: `bin/tk list` печатает `<колонка> T-1 первая задача | <сводка>`.

Проверка: `make check`. Скорость: `make bench`.

## Цикл агента

Агент работает по `RULES.md` (создаётся в `~/tasks` при первой записи). Имя агента берётся из `--as`, затем из `CLAUDE_CODE_SESSION_ID`, `CODEX_THREAD_ID`, `TRACKER_ACTOR`.

| Команда | Что делает |
|---|---|
| `tk ctx [--project p] [--json]` | активные, ждущие и готовые задачи проекта; без git |
| `tk take T-12 [--steal\|--release]` | берёт задачу в работу на 3 часа, перехватывает или отдаёт |
| `tk move T-12 <колонка> [--first\|--after T-9] [-m текст] [--force]` | переносит задачу; проверки входа в `ready`, `waiting`, `closed` |
| `tk set T-12 поле=значение...` | меняет `title`, `waiting`, `due`, `tags`, `ask`, `external`, `abstract`, `summary` |
| `tk check T-12 1 2` | отмечает критерии |
| `tk done T-12 [-m итог] [--force]` | закрывает задачу и снимает захват |
| `tk backup` | коммитит правки мимо ядра и пушит `HEAD` в `origin` |

Коды выхода: 0 успех; 2 занято; 3 конфликт; 4 нет задачи; 5 правило; 6 ввод; 1 прочее.

## Конфигурация

Все переменные необязательны.

| Переменная | Обязательна | Что задаёт |
|---|---|---|
| `TRACKER_HOME` | нет | папка задач, по умолчанию `~/tasks` |
| `TRACKER_LOCK_TIMEOUT` | нет | ожидание лока записи, по умолчанию 5 с |
| `TRACKER_GIT` | нет | путь к git, минуя поиск и кеш |
