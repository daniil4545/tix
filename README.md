# tracker

Личный трекер задач в терминале для человека и агентов (Claude Code, Codex, OpenCode): задачи - md-файлы в `~/tasks` под git, агенты работают через CLI `tk`, человек - через TUI.

## Стадия

Спека MVP. З1 в работе: ядро записи и семь команд `tk` (`new`, `show`, `edit`, `comment`, `note`, `rm`, `list`). TUI, `ctx`, коннекторы - после З1.

## Быстрый старт

Требования: Go 1.27.2, `golangci-lint` 2.x, git.

1. Собрать: `make build` (бинарь `bin/tk`).
2. Задать базу: `export TRACKER_HOME=$HOME/tasks` (без переменной берётся `~/tasks`).
3. Создать задачу: `bin/tk new "первая задача"`.
4. Проверить: `bin/tk list` печатает `<колонка> T-1 первая задача | <сводка>`.

Проверка: `make check`. Скорость: `make bench`.

## Конфигурация

Все переменные необязательны.

| Переменная | Обязательна | Что задаёт |
|---|---|---|
| `TRACKER_HOME` | нет | папка задач, по умолчанию `~/tasks` |
| `TRACKER_LOCK_TIMEOUT` | нет | ожидание лока записи, по умолчанию 5 с |
| `TRACKER_GIT` | нет | путь к git, минуя поиск и кеш |
