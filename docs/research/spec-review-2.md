## Must-fix

N1. spec.md:171, 225-227. Личность без запасного пути. `CODEX_THREAD_ID` не подтверждён.
У OpenCode `--as` из статичного скилла даёт всем сессиям одно имя. Актор коммитов TUI и
человека в шелле не назван, а трейлер `Actor:` обязателен (spec.md:109). Сценарий:
переменной нет, `take` пишет пустой или общий `claim`, перехват сессий ломается молча.
PLAUSIBLE. Предложение: порядок `--as`, переменная агента, `TRACKER_ACTOR`; TUI и шелл - `human`.
Без сессии `take` отвечает отказом с подсказкой.

N2. spec.md:132-133, 101-102, 251. `set` и `edit` с frontmatter могут сменить `status`,
`id`, `created`, `claim`, `rank`. Так обходятся Р40, Р41 и заморозка раздела 8.
`$EDITOR` правит копию целиком, человек меняет `status` в редакторе. CONFIRMED по тексту.
Предложение: `set` принимает только `title`, `waiting`, `due`, `tags`, `ask`, `external`.
Смена `status` в `edit` идёт через проверки `move`. Замороженные поля - отказ.
Раздел `## Комментарии` `edit` только дополняет (раздел 1: правки комментариев нет).

N3. spec.md:99, 154-155. Правка человека теряется на путях отказа. `rev` - blob id файла.
Файл с несохранённой в git правкой Obsidian даёт blob, которого нет в git. Слияние падает.
Отказ из-за маркеров или выход без правки на повторе тоже не описан. Копия в
`.tracker/tmp/` в `.gitignore`, её судьба не названа. PLAUSIBLE, частый путь Obsidian и TUI.
Предложение: чтение пишет blob (`git hash-object -w`). При любом отказе копия остаётся,
путь в строке ошибки. На повторе база - версия, против которой показан конфликт.

## Should-fix

S-a. spec.md:97-98. Сообщение external edit: строка `T-12: external edit` на каждый id,
`Actor: external`. Иначе правки Obsidian не попадут в историю карточки.

S-b. spec.md:106-107, схема 2.1. `pending` хранит путь и сообщение. Коммитится только этот
путь и до шага 2. Иначе правка Obsidian уйдёт под сообщением агента. В схеме нет pending и
цикла повтора.

S-c. spec.md:110, 225. Продление `claim` пишет файл, `note` - пустой коммит. Назвать,
какие команды продлевают. Макет ui.html:159 `note --check 1` меняет файл: убрать или
описать как два действия.

S-d. spec.md:110-111. Коммит не должен зависеть от `user.name` на машине. Передавать
`-c user.name=tracker -c user.email=tracker@localhost`. Иначе `make check` падает на чистой
машине.

S-e. spec.md:143, 156. TUI шлёт операции в фоне. Быстрые `J J J` считают `rank` по
устаревшему виду. Одна очередь операций TUI; `rank` считает ядро под локом по id соседей.

S-f. spec.md:128-131. `~/tasks` - тоже git, проект станет `tasks`. Назвать, что `ctx` и
`new` делают в домашней сессии (все проекты, проект `personal`).

S-g. spec.md:241-243. e2e без фикстуры: задача в `ready` с одним критерием и промпт.
Иначе pass зависит от прихоти агента. Codex: `.git` в writable root только чтение
(spec.md:267). Назвать режим песочницы для e2e. Для `claude -p` назвать `--allowedTools`.

S-h. spec.md:238-239. Гонка 100 записей при ожидании лока 5 с. `flock` не честный,
процесс может ждать дольше на медленной машине. Таймаут в тесте задаётся переменной.

S-i. spec.md:208, 238. Сценарий «коммит упал после rename» нечем вызвать: хуки и подпись
выключены. Нужна точка подмены вызова git в тестах.

S-j. spec.md:224. Текст комментария с `## ` ломает разбор разделов. Всё после
`## Комментарии` считать комментариями.

S-k. spec.md:130. `ctx` до 2000 знаков без правила обрезки при 30 задачах. Первые N по
`rank` и «ещё K».

S-l. spec.md:264. Замер Obsidian требует GUI, агент его не выполнит. Исполнитель -
пользователь, либо принятый риск.
