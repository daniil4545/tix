# Спека: основной путь человека на доске (Р66)

Статус: agreed (решения пользователя 21.10)
Каноны: `docs/spec.md` 2.3, `docs/specs/decisions.md` Р46, Р66, `docs/plans/mvp-finish.md` (раскладка, мышь)
Ветка: `z4-tui`.

## 1. Цель и границы

- Цель: основной путь человека делается на доске без CLI, клавишами и мышью: создать задачу, открыть, перенести, ответить на вопрос агента, комментировать, править текст и поля.
- Не делаем: бэкап, фильтры (после MVP), перестановку порядка мышью, анимацию (v0.2).
- Клавиши `m M` удаляются (решение 21.10): перенос - захват и мышь. `J K` остаются вне подсказки.
- Справка `?` (F): экран со всеми клавишами и действиями мыши, `esc` или `?` - назад.
- Удаление (G): клавиша Delete (`delete` и `backspace`) на доске и в карточке, кнопка `del delete` в строке действий карточки; подтверждение одной клавишей `delete T-12? y/n`, `y` - `Remove`, любая другая - отмена. F привязывает клавиши к `func (m *Model) startDelete() tea.Cmd` (G).

## 3. Поведение: доска (F)

### Подсказка-кнопки

Последняя строка доски: `arrows select  space grab  enter open  n new  a answer  e edit  c comment  o order  p project  ? help  q quit`. Каждая пара «клавиша слово», кроме `arrows select`, - кнопка: клик левой равен нажатию клавиши. Обрезанная по ширине пара не кликается.

### Захват

1. `space` на выбранной карточке - захват. Карточка рисуется стилем захвата (подсветка, маркер `=` вместо `>`), строка состояния: `moving T-12: arrows move, space drop, esc cancel`.
2. `left`/`right` (`h`/`l`) - карточка на экране переезжает в соседнюю колонку, `up`/`down` (`j`/`k`) - меняет место в колонке. До отпускания ничего не пишется.
3. `space` или `enter` - отпускание: один `Move` в выбранную колонку на выбранное место (`First` или `After` соседа сверху) с теми же проверками и строкой ввода, что у `m`. Та же колонка и то же место - ничего.
4. `esc` - отмена, карточка на прежнем месте. Прочие клавиши и мышь при захвате игнорируются.
5. Перечитывание при захвате: задача пропала - отмена и `T-12 removed`; иначе захват держится по id.
6. Порядок по сроку (`o`) включён: захват меняет только колонку, место в колонке не выбирается, строка состояния говорит `order by due: place off`.

### Новая задача

1. `n` или клик по `+` в строке имён колонок (последний знак ячейки колонки, 24-й) - новая задача в этой колонке (`n` - в выбранной).
2. Строка `title:`; пусто или `esc` - отмена.
3. `Create` в эту колонку; проект - текущий фильтр, иначе проект запуска TUI, иначе `personal`.
4. Сразу открывается `$EDITOR` по существующему пути правки с телом-шаблоном из `RULES.md` (`## Abstract`, `## Summary`, `## Details`, `- [ ] `). Выход без правки - задача остаётся с пустым телом.
5. Курсор встаёт на новую задачу.

## 4. Поведение: карточка (G)

1. Строка действий - последняя строка карточки, всегда видна, кнопки как на доске: `e edit  c comment  a answer  f field  g session  del delete  j k history  esc back`. Строка состояния - над ней.
2. Ответ `a` (доска и карточка): у задачи нет `ask` - строка состояния `T-12: no question`. Иначе строка `answer:`; `enter` - одна задача очереди: `Comment` с текстом `Answer: <текст>`; если он прошёл и `ask` в файле всё ещё тот, на который отвечали, - `Set ask=""`; агент успел задать новый вопрос - вопрос остаётся, строка состояния `T-12: new question`. Пусто или `esc` - отмена. Клик по строке `* needs you:` в карточке - то же. Известная гонка: условная запись `ask` - v0.2.
3. Поля `f`: строка `field: t title  d due  g tags  a ask  w waiting  s summary  x external`, выбор буквой или кликом по паре. Затем строка `<поле>:` с текущим значением; `enter` - `Set` этого поля, пусто - очистить, значение не изменилось - записи нет; отказ ядра - текст в строке состояния. Значение в несколько строк (обычно `summary`) строкой не правится: `T-12: summary has several lines, use e`. Клик по строке полей карточки открывает тот же выбор.
4. Критерии (G): строки `- [ ]` и `- [x]` тела выбираются теми же `j k` и стрелками, что записи истории (сначала критерии, потом история); `enter` или клик по строке критерия - отметить (`Check`) или снять (правка тела через `Edit` с базой `rev`: `[x]` на `[ ]` в этой строке). У записи истории `enter` - как сейчас.
5. Клик по пустому месту карточки - ничего; колёсико - как сейчас.

## 4a. Переход в сессию агента (H)

Факт 21.10 (проверено пользователем): у вкладки Warp есть `WARP_FOCUS_URL=warp://session/<32 hex>`, `open <url>` переключает на неё.

1. Любая команда записи агента (личность не `human`), если в окружении есть `WARP_FOCUS_URL` вида `^warp://session/[0-9a-f]{32}$`, пишет его в `os.UserCacheDir()/tk/focus/<агент>-<id сессии>` (на macOS `~/Library/Caches/tk/focus`; `TRACKER_FOCUS_DIR` перекрывает путь; 0600, одна строка). Файл - данные машины, в `~/tasks` и git не попадает. Иное значение не пишется. Ошибка записи файла - Warn в лог, команда не падает.
2. `g` на доске и в карточке и кнопка `g session` в строке действий карточки: у задачи живой захват, файл фокуса его владельца есть и проходит ту же проверку - запуск `open <url>` без ожидания. Иначе строка состояния `T-12: no session to open`.
3. Другие терминалы (Ghostty, iTerm2, tmux) - тем же файлом с другим видом адреса, после выбора терминала.

## 5. Сценарии для тестов (T)

1. Подсказка-кнопки: клик по `n new` открывает строку `title:`; клик по `q quit` выходит; обрезанная пара не срабатывает.
2. Захват: `space`, `right`, `space` - задача в соседней колонке, один коммит; `space`, `down`, `space` - место в колонке; `space`, `right`, `esc` - коммита нет; захват в `blocked` спрашивает `waiting for:`.
3. Захват и перечитывание: задачу удалили в другом окне - `removed`, захват снят.
4. Новая задача: клик по `+` колонки `todo`, заголовок, редактор-заглушка без правки - задача в `todo` с заголовком; с правкой - тело из редактора.
5. Ответ: `a` без вопроса - `no question`; с вопросом - комментарий `Answer: ...` и `ask` пуст; клик по строке вопроса в карточке открывает `answer:`.
6. Поля: `f`, `d`, `2026-11-01`, `enter` - срок записан; пустое значение очищает; отказ ядра виден.
7. Строка действий карточки видна при непустой строке состояния; клик по `c comment` открывает строку комментария.
8a. Критерий: `j` до пункта, `enter` - отмечен, `enter` ещё раз - снят; клик по `[ ]` - отмечен.
8. Удаление: Delete, `n` - задача на месте; Delete, `y` - задачи нет. `m` больше ничего не делает. `?` открывает справку.
9. Фокус: команда агента с `WARP_FOCUS_URL` пишет файл; значение не того вида не пишется; `g` без захвата - `no session to open`; с захватом - вызов `open` с адресом (подменённая команда).
