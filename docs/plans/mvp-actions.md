# Спека: основной путь человека на доске (Р66)

Статус: agreed (решения пользователя 21.10)
Каноны: `docs/spec.md` 2.3, `docs/specs/decisions.md` Р46, Р66, `docs/plans/mvp-finish.md` (раскладка, мышь)
Ветка: `z4-tui`.

## 1. Цель и границы

- Цель: основной путь человека делается на доске без CLI, клавишами и мышью: создать задачу, открыть, перенести, ответить на вопрос агента, комментировать, править текст и поля.
- Не делаем: отметку критериев, удаление, бэкап, справку `?`, перестановку порядка мышью, анимацию (v0.2), переход в сессию агента (разведка).
- Клавиши `m M J K` остаются, но из подсказки уходят: основной перенос - захват.

Стыки F и G (сигнатуры фиксированы):

- F вызывает их: `a` в `boardKey` и `cardKey` - `startAnswer`; `f` в `cardKey` - `startField`; клик мыши при открытой карточке - `cardClick`.
- G добавляет в `input.go` строку ввода с начальным значением: `func (m *Model) askWith(label, initial string, done func(string) tea.Cmd)`; F её использует для заголовка новой задачи.

## 3. Поведение: доска (F)

### Подсказка-кнопки

Последняя строка доски: `arrows select  space grab  enter open  n new  a answer  e edit  c comment  o order  p project  q quit`. Каждая пара «клавиша слово», кроме `arrows select`, - кнопка: клик левой равен нажатию клавиши. Обрезанная по ширине пара не кликается.

### Захват

1. `space` на выбранной карточке - захват. Карточка рисуется стилем захвата (подсветка, маркер `=` вместо `>`), строка состояния: `moving T-12: arrows move, space drop, esc cancel`.
2. `left`/`right` (`h`/`l`) - карточка на экране переезжает в соседнюю колонку, `up`/`down` (`j`/`k`) - меняет место в колонке. До отпускания ничего не пишется.
3. `space` или `enter` - отпускание: один `Move` в выбранную колонку на выбранное место (`First` или `After` соседа сверху) с теми же проверками и строкой ввода, что у `m`. Та же колонка и то же место - ничего.
4. `esc` - отмена, карточка на прежнем месте. Прочие клавиши и мышь при захвате игнорируются.
5. Перечитывание при захвате: задача пропала - отмена и `T-12 removed`; иначе захват держится по id.
6. Порядок по сроку (`o`) включён: захват меняет только колонку, место в колонке не выбирается, строка состояния говорит `order by due: place off`.

### Новая задача

1. `n` или клик по `+` в строке имён колонок (последний знак ячейки колонки, 24-й) - новая задача в этой колонке (`n` - в выбранной).
2. Строка `title:`; пусто или `esc` - отмена.
3. `Create` в эту колонку; проект - текущий фильтр, иначе проект запуска TUI, иначе `personal`.
4. Сразу открывается `$EDITOR` по существующему пути правки с телом-шаблоном из `RULES.md` (`## Abstract`, `## Summary`, `## Details`, `- [ ] `). Выход без правки - задача остаётся с пустым телом.
5. Курсор встаёт на новую задачу.

## 4. Поведение: карточка (G)

1. Строка действий - последняя строка карточки, всегда видна, кнопки как на доске: `e edit  c comment  a answer  f field  m M move  j k history  esc back`. Строка состояния - над ней.
2. Ответ `a` (доска и карточка): у задачи нет `ask` - строка состояния `T-12: no question`. Иначе строка `answer:`; `enter` - `Comment` с текстом `Answer: <текст>`, затем `Set ask=""`; пусто или `esc` - отмена. Клик по строке `* needs you:` в карточке - то же.
3. Поля `f`: строка `field: t title  d due  g tags  a ask  w waiting  s summary  x external`, выбор буквой или кликом по паре. Затем строка `<поле>:` с текущим значением; `enter` - `Set` этого поля, пусто - очистить; отказ ядра - текст в строке состояния. Клик по строке полей карточки открывает тот же выбор.
4. Клик по пустому месту карточки - ничего; колёсико - как сейчас.

## 5. Сценарии для тестов (T)

1. Подсказка-кнопки: клик по `n new` открывает строку `title:`; клик по `q quit` выходит; обрезанная пара не срабатывает.
2. Захват: `space`, `right`, `space` - задача в соседней колонке, один коммит; `space`, `down`, `space` - место в колонке; `space`, `right`, `esc` - коммита нет; захват в `blocked` спрашивает `waiting for:`.
3. Захват и перечитывание: задачу удалили в другом окне - `removed`, захват снят.
4. Новая задача: клик по `+` колонки `todo`, заголовок, редактор-заглушка без правки - задача в `todo` с заголовком; с правкой - тело из редактора.
5. Ответ: `a` без вопроса - `no question`; с вопросом - комментарий `Answer: ...` и `ask` пуст; клик по строке вопроса в карточке открывает `answer:`.
6. Поля: `f`, `d`, `2026-11-01`, `enter` - срок записан; пустое значение очищает; отказ ядра виден.
7. Строка действий карточки видна при непустой строке состояния; клик по `c comment` открывает строку комментария.
