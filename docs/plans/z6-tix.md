# Спека: переименование в tix (Р67)

Статус: agreed (решение пользователя 21.10)
Ветка: `z6-tix` (дерево `../tracker-z6`). Перевод на английский (T-12) - следующим шагом в этой же ветке.

## 1. Что меняется

| Что | Было | Стало |
|---|---|---|
| модуль Go | `tracker` | `github.com/daniil4545/tix` |
| команда и бинарь | `cmd/tk`, `bin/tk` | `cmd/tix`, `bin/tix`; `cmd/tkbench` - `cmd/tixbench` |
| переменные окружения | `TRACKER_*` (HOME, ACTOR, MODEL, FOCUS_DIR, INBOX_DIR, GIT, TUI_ONESHOT и др.) | `TIX_*` с тем же хвостом |
| служебная папка базы | `<база>/.tracker/` | `<база>/.tix/` |
| каталоги кэша | `os.UserCacheDir()/tk/...` | `os.UserCacheDir()/tix/...` |
| скилл агентов | `connectors/agents/skills/tk`, имя `tk` | `.../skills/tix`, имя `tix` |
| хуки и правила | `tk ctx --hook`, `tk inbox --hook`, `prefix_rule` для `tk` | то же с `tix` |
| тексты | `tk` в `RULES.md`, справке, ошибках, README, спеке | `tix` |
| версия | нет | `tix --version`, значение через `-ldflags "-X main.version=..."`, без него `dev` |

Папка задач `~/tasks` не меняется. Имя `tk` в коде и текстах не остаётся, кроме раздела миграции.

## 2. Миграция у существующего пользователя

1. Служебная папка: при открытии базы, если есть `.tracker` и нет `.tix`, ядро переименовывает `.tracker` в `.tix` (`os.Rename`, атомарно; гонка двух процессов - второй видит `.tix`). До rename `.gitignore` базы переводится на `.tix`: строки `.tracker/...` и `/.tracker/...` меняются, недостающие служебные строки `.tix/` дописываются. Изменение коммитит следующая запись ядра. Есть обе папки - `.tracker` не трогается, `.gitignore` только получает строки `.tix/`. Первое открытие пишет в базу: база только для чтения (песочница агента) до миграции не откроется.
2. `connect.sh apply` переносит базу вызовом `tix list`, своей копии миграции у скрипта нет. узнаёт поставленные раньше хуки `tk ctx`, `tk ctx --hook`, `tk inbox --hook` и меняет их на `tix ...`; скилл `tk` снимает и ставит `tix`; правило Codex для `tk` меняет на `tix`. `undo` снимает новое.
3. Кэш `.../tk/` не переносится: отметки доставки и фокус пересоздаются при следующих вызовах.
4. Старые переменные `TRACKER_*` не читаются.
5. Локальная ссылка `~/bin/tk` у пользователя остаётся (вне репозитория) и указывает на новый бинарь `bin/tix`: запущенные сессии со старыми хуками работают до перезапуска. Старый бинарь после миграции пересоздал бы `.tracker`.

## 3. Проверка

- `make check` и `scripts/test-connect.sh` зелёные.
- `grep -rn 'TRACKER_\|"tracker/\|\.tracker' --include='*.go' --include='*.sh' .` - пусто, кроме теста миграции.
- Тест миграции: база с `.tracker` и записью в `.gitignore` - после первой команды есть `.tix`, нет `.tracker`, задачи и лог на месте, `.gitignore` обновлён.
- `tix --version` печатает `dev` без ldflags и значение с ними.
